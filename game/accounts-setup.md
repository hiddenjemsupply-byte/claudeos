# Jemfall: Accounts Setup

Do these in order. Each step uses the one before it.

## 1. Gmail (the master login)
* Try in order: jemfall@gmail.com, jemfallgame@gmail.com, playjemfall@gmail.com
* Every Jemfall account below gets created with this Gmail. One login owns everything.
* Turn on 2 step verification right away (Google Account, Security).

## 2. Domain
* Buy jemfall.com at Cloudflare Registrar (sells at cost, about $10 a year). Use the Gmail.
* Turn on auto renew. If the domain lapses, someone else can take it.

## 3. Public email
* In Cloudflare, turn on Email Routing (free). Make hello@jemfall.com forward to the Gmail.
* hello@jemfall.com goes in bios and on the website. The Gmail stays private as the login.
* Later, when you need to send email from hello@jemfall.com, upgrade to Google Workspace (paid).

## 4. Socials
